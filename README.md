# Personal portfolio

I'm Mikel Pastor, and this is my personal website and portfolio. Here I share my projects, a little about myself, and ways to get in touch.

I've kept the design simple and clean, with warm neutral colors, a green accent, and subtle animations.

## Features

- Available in Spanish and English.
- Responsive layouts for mobile and desktop.
- Light, dark, and system themes.
- Keyboard navigation and support for reduced motion preferences.
- Profile, projects, and links editable through JSON.

I'm still adding content, so unfinished sections are clearly labeled as placeholders.

## Technologies

I built it with **React**, **TypeScript**, **Vite**, and **CSS**.
